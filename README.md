저장소 초기화 및 연결

!git init : 현재 폴더를 새로운 Git 로컬 저장소로 초기화함.

!git remote add origin [레포지토리URL] : 로컬 저장소와 GitHub 원격 저장소를 연결함.

!git status : Git에 추가되었거나 수정된 파일들의 현재 상태를 확인함.

파일 추가 및 기록 (커밋)

!git add . : 현재 폴더 내의 모든 변경된 파일과 새 파일을 추적 대상에 한 번에 추가함.

!git add [파일명.m] : 변경된 파일 중 특정 파일만 선택하여 추적 대상에 추가함.

!git commit -m "메시지 내용" : 추가된 파일들을 작성한 메시지와 함께 로컬 저장소에 하나의 버전으로 기록함.

원격 저장소 업로드 (푸시)

!git branch -M main : 기본 작업 브랜치(Branch) 이름을 main으로 통일함.

!git push -u origin main : 초기 연결 후 처음으로 코드를 GitHub에 업로드하고 연결 정보를 기억시킴.

!git push : 최초 업로드 세팅 이후부터 코드를 올릴 때 추가 옵션 없이 간단히 사용함.

기록 수정 및 강제 조치

!git commit --amend -m "새로운 메시지" : 가장 최근에 완료한 커밋의 메시지를 새로운 내용으로 덮어씀.

!git reset HEAD~1 : 파일의 수정 내용은 그대로 유지한 채, 가장 최근의 커밋 기록 1개만 취소함.

!git push -f origin main : 메시지 수정이나 되돌리기 등으로 로컬 기록이 변경되었을 때 이를 GitHub에 강제로 덮어씌움.

!rmdir /s /q .git : 기존에 잘못 설정된 Git 폴더와 기록을 로컬 환경에서 완전히 삭제함.
